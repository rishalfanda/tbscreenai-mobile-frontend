Dokumen lintas tim mencakup gambaran produk, schema backend, workflow perubahan API, deployment, incident ownership, dan rencana takeover 30 hari.

Status istilah:

- **VERIFIED**: dikonfirmasi dari source/config/test pada 20 Agustus 2026.
- **KNOWN RISK**: masalah yang sudah diketahui.
- **NOT IMPLEMENTED**: jangan dianggap fitur selesai.
- **OPEN DECISION**: perlu keputusan product/technical owner.

Source code, test, dan generated API contract lebih tinggi prioritasnya daripada dokumentasi naratif jika terjadi konflik. Perbedaan harus diperbaiki dalam PR yang sama, bukan dibiarkan menjadi pengetahuan lisan.
